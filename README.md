# 임윤지 포트폴리오

안녕하세요 👋  
UX/UI 디자인과 퍼블리싱을 중심으로 진행한 포트폴리오 프로젝트 레포지토리입니다.  
각 프로젝트는 기획 → 디자인 → 퍼블리싱 과정을 거쳐 직접 구현하였습니다.  
본 README에서 전체 프로젝트 개요와 시연 페이지를 확인하실 수 있습니다.

---

## 🛠 기술 스택

### 🎨 디자인 툴
- Adobe Photoshop, Illustrator, After Effects  
- Sketch, Zeplin  
- 3D 디자인: Rhino, KeyShot, CAD

### 💻 퍼블리싱
- HTML5, CSS3  
- JavaScript (기본 DOM 조작)  
- 반응형 웹 디자인 (Media Query 사용)

---

## 📂 프로젝트 목록

---

### 🏦 삼성카드 UX Design
- **개요**: 삼성카드 UX디자인실에서 앱 전반의 그래픽과 UI 담당  
스플래시 아트, 앱과 신규 모니모 앱의 배너·모션그래픽, 챗봇 비주얼, 데이터랩 썸네일, UI 아이콘 및 금융 탭 개선, 다양한 서비스 내 프로모션 그래픽 제작
- **시연 페이지**: [👉 바로가기](https://ottlzi.github.io/IMYUNJI-ARCHIVE/imyunji/content_samsungcard.html)
- **저작권 안내**: ※ 본 프로젝트에서 사용된 화면 캡처 및 그래픽은 모두 본인이 제작한 자료입니다.  
삼성카드 시스템의 실제 운영계에 반영된 화면을 캡처하여 사용하였으며,  
삼성카드의 상표, UI 요소 및 서비스 화면은 원저작권자에게 귀속됩니다.  
본 포트폴리오는 비상업적 포트폴리오 목적으로만 사용되었습니다.

---

### 🐾 붐펫 반려동물 쇼핑 웹사이트
- **개요**: 반려동물 라이프스타일 중심 쇼핑 웹사이트 클론 프로젝트
- **주요 기여**: 정보 구조 설계, 와이어프레임, 스타일 가이드, 스토리보드, 반응형 웹 퍼블리싱
- **시연 페이지**: [👉 바로가기](https://ottlzi.github.io/IMYUNJI-ARCHIVE/vuumpet/vuumpet_main.html)
- **저작권 안내**: 로고 및 브랜드 이미지는 원저작권자에게 귀속되며, 본 프로젝트는 **비상업적 학습 및 포트폴리오 목적**으로 제작되었습니다.

---

### 🛍 리사이클링 소품샵 웹사이트
- **개요**: 무분별한 플라스틱 사용을 지양하는 라이프 소품샵  
도시 탄소 중립과 리사이클링 작가·소비자를 지지하는 목적으로 제작
- **시연 페이지**: [👉 바로가기](https://ottlzi.github.io/IMYUNJI-ARCHIVE/imyunji/livingshop.html)

---

### 🖋 Industrial & Editorial Design 🎨 
- **개요**: 산업 디자인 및 편집 디자인 관련 다수 프로젝트를 포함  
책, 브로슈어, 패키지, 포스터 등 다양한 시각 디자인 작업 수행  
- **주요 프로젝트 예시**:
  - 펫 스트롤러, 공기청정기, 시계 등 **3D 프로그램(Rhino, KeyShot, CAD) 활용 컨셉 디자인**
  - 브로슈어 디자인, 제품 패키지 시안  
  - 포스터, 홍보물, 브랜드 아이덴티티 관련 그래픽 작업
- **저작권 안내**: 모든 디자인은 본인이 제작하였으며, 외부 브랜드/저작권 자료 사용 시 학습 및 포트폴리오 목적으로만 활용하였습니다.

## 📌 참고 사항
- 일부 프로젝트는 **클론 코딩 기반**이며, 학습 및 포트폴리오 목적으로 제작되었습니다.  
- 배포 페이지 및 깃허브 저장소에서 확인 가능한 이미지/리소스는 저작권 문제가 없는 범위 내에서 사용했습니다.
